# 성심당 브랜드 웹페이지

Figma의 지정된 19개 프레임을 원본 HTML 레이어와 CSS로 구현한 정적 웹사이트입니다.

## 수정할 파일

- `index.html`: 프레임별 요소, 문구, 이미지, 링크. 각 구간에 프레임 이름과 원본 `data-node-id`가 있습니다.
- `styles.css`: 레이어별 위치, 크기, 색상, 폰트, 효과. `f01`은 Landing, `f02`는 Intro이며 프레임별 주석으로 구분됩니다.
- `script.js`: 스크롤 구간과 화면 전환.
- `assets/`: Figma 원본 이미지, SVG, Pretendard 폰트.
- `figma-source.json`: 원본 프레임, 레이어 ID 순서, 이미지 슬롯 매핑.

설치나 빌드 없이 `index.html`을 브라우저에서 열면 실행됩니다.

## 화면 순서

Landing → Intro → History → History_content_start → History_content_mid → History_content_end → bridge_scale → bridge_scale_end → with Daejeon → bridge_fade_1 → bridge_fade_2 → bridge_fade_3 → Table → Table_tilt → Our Way_start → Our Way_mid → Our Way_end → Brand → Contact

## 스크롤

각 화면의 내부 스크롤을 먼저 진행합니다. 화면 끝에 도착하면 마지막 위치와 투명도를 1,500px 스크롤 동안 그대로 유지하고, 그 이후 별도의 250px 구간에서 다음 화면으로 전환합니다. Landing → Intro는 유지 구간을 적용하지 않습니다.

Table_tilt → Our Way_start에서는 이전 화면이 검정으로 페이드 아웃되고 검정 화면을 거쳐 다음 화면이 페이드 인됩니다. 역방향도 동일합니다.

원본의 가로·세로 비율을 유지합니다. 작은 화면에서도 별도 모바일 요소를 복제하거나 원본과 다른 배치로 바꾸지 않습니다.

## Intro 연출

첫 소개 문구는 Landing과 같은 원본 좌표(1340, 488)에 있습니다. 빵은 내부 스크롤의 76%까지 화면 중앙에서 고정되며 마지막 24% 구간에 아래로만 이동합니다. 손 이미지는 오른쪽으로 21px 이동하여 빵 중심과 맞췄습니다. 빵은 내부 스크롤에 따라 시계방향으로 한 바퀴 회전합니다. 왼쪽 하단의 노란 그라데이션은 Intro 시작부터 고정 표시됩니다. 모션 감소 설정에서는 회전을 생략합니다. 좌우 문구는 스크롤을 따라 이동하지 않고, 같은 자리에서 줄마다 아래에서 슬라이드·페이드 인되고 위로 슬라이드·페이드 아웃됩니다. 마지막 문구와 빵의 착지 상태는 화면 끝의 1,500px 유지 구간에도 고정됩니다. 추가 요소나 이미지 복제는 없습니다.

## 공통 헤더

Landing의 원본 로고와 내비게이션을 공통 헤더로 이동했습니다. 긴 콘텐츠와 화면 전환의 영향을 받지 않고 상단에 고정됩니다. Landing → Intro 구간에서 로고가 365.299×147에서 124×50으로 부드럽게 줄어들고, 밝은 Our Way_end 화면에서는 검정 로고·메뉴로 전환됩니다. 활성 메뉴 밑줄도 화면 전환에 맞춰 교차 전환됩니다. 본문 중앙 워드마크와 Brand 하단 로고는 그대로 유지됩니다.

## History 연출

Intro → History 전환에서 손 위 빵의 위치·크기를 History 중앙으로 이어서 보간하고, 기존 두 빵 이미지가 교차 전환됩니다. History 진입 후 600px 스크롤 동안 네 모서리에서 각각 시계방향으로 점선이 그려집니다. 선이 완성된 뒤 다음 400px에서 배경 문구가 오른쪽으로부터 들어옵니다. 완성된 화면을 1,500px 유지한 뒤 다음 프레임으로 전환합니다. 역방향 스크롤에서도 순서가 자연스럽게 되돌아갑니다.

History → History_content_start에서는 점선이 500×500에서 610×732로 확대되며 다음 프레임의 위치로 연결됩니다. 포장된 빵은 뒤쪽으로 회전해 사라지고, 다음 사진은 점선 전환이 끝난 후 blur/fade로 나타납니다. 문구가 진입을 마치면 1.5초 glow가 재생되고, 다음 전환 구간에서 240px 제목이 다음 프레임의 36px 문구 위치(68, 252)로 이동·축소됩니다. 기존 1,500px 유지 구간을 보존했습니다.

History_content_start의 중앙 사진은 회전 없이 처음 400px에서 흐림·투명 상태로부터 선명하게 나타납니다. 중앙 사진이 완성된 뒤 바깥 사진들은 오른쪽에서 차례로 진입합니다. 왼쪽 ‘성심당의 이야기’는 아래에서 슬라이드·페이드 인되고, 화면 전환 시 아래로 슬라이드·페이드 아웃됩니다. 각 연출 구간이 완료된 후 1,500px 유지 구간이 이어집니다.

History_content_start → mid → end는 start의 원본 공통 레이어를 계속 표시합니다. 점선·문구·배경은 교차 페이드 없이 유지하고, 9장의 사진은 인접한 다음 사진부터 순서대로 중앙으로 이동합니다. 중앙 사진은 600×720 / opacity 1, 주변 사진은 250×300 / opacity 0.6이며 이동 중 연속 보간됩니다. mid는 사진 1→4, end는 사진 4→9를 사진별 700px 이동 + 1,500px 유지로 순서대로 이동시켜 원본 프레임의 최종 구도와 연결합니다.

중앙 점선(f04-layer-047)의 inset 그림자를 제거했습니다. 모든 중앙 사진은 이동을 마친 뒤 동일하게 1,500px 유지됩니다. 프레임 마지막 사진은 기존 프레임 유지 구간을 사용하여 중복 유지하지 않습니다.

최신 조정: History_content 중앙 사진의 유지 구간은 모두 1,000px이며, 다른 화면의 1,500px 유지 구간은 그대로입니다. History 오른쪽 진입 문구는 400px에서 800px 스크롤 거리로 늘려 절반 속도로 이동합니다. 문구 완성 및 glow 시작 기준도 1,400px로 맞췄습니다.

History 진입 후 1,000px는 점선을 표시하지 않습니다. 이후 600px 동안 점선을 그리고, 다음 800px에서 문구가 진입합니다. 완성 후 유지 구간과 다음 전환은 동일합니다.

History 점선 최신 타이밍: 등장 전 800px 유지 → 1,200px 동안 점선 생성 → 800px 동안 문구 진입. 점선 생성 속도는 이전의 절반입니다.

중앙 사진 이동은 700px → 1,000px로 늘렸으며, quintic smootherstep을 적용해 출발·도착 지점에서 속도와 가속도가 모두 0으로 이어집니다. 사진별 1,000px 유지 구간은 그대로입니다.

사진별 유지 구간 최신값: 800px. 이동 구간 1,000px와 천천히 출발·도착하는 easing은 유지합니다.

History_content_end의 마지막 중앙 사진은 다음 전환에서 600×720 → 784×1030으로 확대됩니다. bridge_scale에서 1,000px 동안 1582×1020으로, bridge_scale_end에서 1,000px 동안 2064×1020으로 확대되며 with Daejeon 배경과 연결됩니다. 이미지 크기·위치·내부 크롭을 보간하고 점선·문구·주변 사진은 확대에 맞춰 사라집니다. 기존 사진별 800px와 프레임별 유지 구간은 보존됩니다.

f07-layer-005 → f08-layer-005: bridge_scale 끝의 1,500px 유지와 250px 전환 구간을 제거했습니다. 원본 두 사진을 공통 레이어로 이동하고 f08을 뒤에 선배치했습니다. 고해상도 사진을 preload하고, f07이 확대되는 동안 뒤의 f08이 드러나며 다음 확대가 즉시 이어집니다.

마지막 사진 확대 전환의 간판 정렬: 350×241 목록 사진과 350×292 bridge 사진의 상단 52px 차이를 보정했습니다. 두 사진의 흰 간판 글씨가 같은 위치에서 겹치도록 크롭을 연동하며, 고해상도 사진도 간판 글씨의 중심·bbox 크기를 기준으로 정렬합니다. 고해상도 사진으로의 교차 전환이 끝난 뒤에만 최종 with Daejeon 크롭으로 이동합니다. verify-image-alignment.cjs가 두 교차 전환의 글씨 중심·배율 일치를 확인합니다.

with Daejeon: 확대가 완료된 상태에서 패널이 500px 동안 좌측에서 슬라이드·페이드 인됩니다. 진입 완료 후 추가 300px를 스크롤하면, 본문과 결론 문구가 줄별 70px 간격으로 위에서 내려오며 페이드 인됩니다. 전체 1,700px 연출 완료 후 기존 화면 유지 구간이 이어집니다.

with Daejeon 퇴장: 완료 화면 유지 후 마지막 문구 줄부터 위로 역순 슬라이드·페이드 아웃하고, 패널이 왼쪽으로 사라집니다. 그 다음 배경을 왼쪽으로 이동하면서 간판 흰 글씨의 중심·배율을 f10-layer-024에 맞춥니다. 정렬 완료 후에만 배경 사진의 opacity가 0으로 내려가고 원본 로고가 1로 올라옵니다. f10 원본 로고를 공통 오버레이로 이동해 섹션 경계에서도 유지합니다.

배경 간판 정렬 시 width 159.93%, height 270%를 고정하고 left/top만 이동합니다. 가로·세로 배율 보간을 제거하여 사진이 눌리거나 늘어나지 않습니다.

간판→로고 정렬 보정: 고해상도 사진의 흰 획과 로고의 알파 마스크를 균일 배율로 대조해, 원본 사진 좌표 (1530, 634), 배율 2.85 기준으로 로고의 위치·크기를 맞췄습니다. 배경 이미지 크기는 고정합니다. 반투명 교차 구간을 줄여 이중 획 잔상을 완화했습니다.

기본 상호작용 easing은 CSS ease-in-out과 동일한 cubic-bezier(0.42, 0, 0.58, 1)로 통일했습니다. 기존 사진용 별도 smootherstep과 빵의 선형 회전도 공통 easing을 사용합니다. data-scene=9 → 10의 로고 축소 구간은 250px에서 600px로 늘렸습니다.

data-scene=13 → 14 검정 페이드 구간은 1,000px입니다. 검정 오버레이를 design-stage 안으로 옮겨 본문만 가리며, 공통 헤더는 더 높은 z-index에서 계속 표시됩니다.

포장지 찢기: built-in image_gen으로 투명 중간 프레임 3장(early/wide/final)을 생성했습니다. 원본 2장과 5단계 시퀀스로 연결하며 14→15와 15→16은 각각 1,000px, 공통 ease-in-out을 사용합니다. 마지막 종이 조각은 위·아래로 벗겨집니다. 자산과 전체 생성 프롬프트는 assets/wrapper-generation.json에 기록했습니다. 원본 이미지는 덮어쓰지 않았습니다.

포장지 최신 동작: 전체 1,500px에서 100px당 1단계, 총 15단계로 진행합니다. 기존 생성 이미지 5개 상태를 사용하며 각 상태 사이에 종이 위·아래 이동 단계를 추가합니다. 교차 페이드와 종이 opacity 보간을 제거했습니다. scene14 전환 700px + scene15 전환 800px이며 중간 유지 구간은 없습니다.

현재 포장지 구현은 별도로 생성한 완성 이미지 15장을 직접 교체합니다. 1~8번은 wrapper-tear-frames-v2를 유지하고, 9~15번은 wrapper-tear-frames-v3에 각각 새로 생성했습니다. 전체 이미지를 왼쪽으로 이동하는 처리는 취소했습니다. 왼쪽 끝의 좁은 틈과 고정점을 유지하면서 찢어진 대각선 경계가 가팔라지고 종이의 오른쪽 범위가 줄어듭니다. 100px마다 한 장씩 표시하며 교차 페이드가 없습니다. 생성 도구는 built-in image_gen이며 프롬프트·원본 생성 식별자·SHA256·투명 영역 검수값은 assets/wrapper-generation-v3.json, 8~15번 비교 이미지는 wrapper-frames-09-15-review.jpg에 저장했습니다.

16~20번은 왼쪽 끝의 고정을 풀어 틈을 벌리고, 종이가 왼쪽 위·아래 모서리 밖으로 벗겨지는 완성 이미지 5장을 추가 생성했습니다. assets/wrapper-tear-frames-v4에 저장했으며 전체 20단계는 100px씩 총 2,000px입니다(scene14 전환 700px + scene15 전환 1,300px). 생성 프롬프트와 자산 기록은 assets/wrapper-generation-v4.json, 비교 이미지는 wrapper-frames-15-20-review.jpg입니다. scene14의 글은 진입 페이드가 끝나고 opacity가 1인 scene14에 도착한 뒤에만 표시합니다. 역방향에서도 진입 구간에서는 숨깁니다.

종이 찢기 2,000px 완료 후 scene15의 포장지 없는 화면을 500px 유지하고, 이어지는 250px 동안 scene15와 scene16을 ease-in-out으로 교차 페이드합니다. scene15의 전체 진행 구간은 찢기 1,300px + 유지 500px + 교차 페이드 250px입니다. 공통 로고와 내비게이션의 색상은 찢기와 유지 구간 내내 고정되며 교차 페이드가 시작된 뒤 scene16의 색상으로 변합니다.

scene16은 교차 페이드 완료 후 첫 화면을 800px 유지한 뒤 내부 콘텐츠 스크롤을 시작합니다. 콘텐츠 마지막의 기존 유지 구간은 그대로 적용합니다.

최신 공통 규칙: Landing을 포함한 모든 19개 화면은 진입/전환 완료 후 시작 화면을 1,000px 스크롤 동안 고정합니다. 이 구간에는 내부 콘텐츠 위치와 스크롤 기반 효과 진행도를 모두 0으로 유지하고, 이후 기존 스크롤·효과·끝부분 유지·전환을 진행합니다. scene16의 기존 800px 진입 고정도 1,000px로 통일했습니다.

HTML iframe의 data-camera-distance(기본 1.05)가 작을수록 크게 표시됩니다. 뷰어 입력은 꺼서 스크롤을 가로채지 않습니다. 준비 완료 전 및 로딩/API 오류 시에는 원본 이미지를 표시합니다. 투명 배경과 뷰어 UI 숨김 옵션은 Sketchfab 계정/모델 권한에 따라 제한될 수 있습니다. 출처: https://sketchfab.com/3d-models/bread-01-8ca58505f79f439383097d522f25b60a
